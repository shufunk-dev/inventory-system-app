# Multi-Store and Booth Configurations

In **Store Mode**, the system supports running multi-vendor setups, antique malls, consignment shops, or multiple physical locations from a single web dashboard. This page explains how to partition inventory, configure booth settings, and handle barcode tags.

---

## 1. Booth Setups and Management

To create and manage stores or individual booth rentals:
1. Navigate to the **Admin Dashboard** (accessible only to users with the Admin role).
2. Click on **Store Profiles**.
3. Select **Add Store** to define a new partition.
4. Input details:
   * **Store ID**: A short, alphanumeric string (e.g. `booth-101`, `location-east`).
   * **Name**: The display name (e.g., "A1 Antique Collectibles", "Shufelt Designs Store").
   * **Vendor Commission Rate**: The percentage cut the store owner takes from sales (e.g., `10%`).
   * **Tax Rate**: Default sales tax applied at checkout.

---

## 2. Sequence Partitioning

To prevent transaction conflicts when multiple stores operate offline or sync databases, the system partitions sequence IDs:

* **Item Barcode Prefixing**: Each store can be assigned a prefix. Autogenerated item numbers will automatically prepend this prefix (e.g. `SD-0001` vs `AC-0001`).
* **Receipt/Invoice Sequences**: Invoices are partitioned to prevent overlapping receipt IDs. For example, Store A receipts follow sequence `REC-A-00001` while Store B receipts follow `REC-B-00001`.
* **Database Offsets**: In environments syncing decentralized sqlite databases, Primary Keys (`id`) are generated using UUID v4 strings to prevent collisions entirely.

## 3. Printing Tag Toggles (Name vs. Number)

The system includes a barcode label printing tool that supports standard Brother, Zebra, and DYMO label writers. You can customize what metadata prints on the item tag:

### A. Tag Layout Options
You can configure these toggles under **Settings** > **Printer Settings**:
* **Print Store Name**: Prints the name of the store/booth at the top of the tag. Useful for consignment malls so buyers and cashiers can easily identify which booth the item belongs to.
* **Print Store Number/ID**: Prints only the short Store ID (e.g. `B101`) instead of the full name. This saves precious label space on small 1" x 1.5" jewelry tags.
* **Print Item Title & Price**: Toggles whether to print the user-friendly title and the retail price on the tag.

### B. Standard Tag vs. Compact Tag
* **Standard (2" x 1")**: Contains Store Name, Item Title, Barcode, Item ID, and Price.
* **Compact (1.2" x 0.8" / Rat-tail)**: Contains only the Barcode and Price, with the Store ID printed in small text.
